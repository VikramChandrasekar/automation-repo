# Enterprise Selenium Java + TestNG UI Automation Framework

**Author:** Vikram MC — QA Automation Architect / Tech Lead SDET[cite: 1]

## Production Architecture & Capabilities
- **ThreadLocal WebDriver Management:** Complete thread safety during parallel execution across TestNG threads[cite: 1, 2].
- **Fluent Page Object Model (POM):** Clean encapsulation of locators and actions using PageFactory.
- **Automated Driver Binaries:** Integrated with WebDriverManager for seamless multi-browser execution.
- **CI/CD Quality Gate:** Automated Maven execution pipeline via GitHub Actions[cite: 1].
